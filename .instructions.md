## Pipeline ETL

La conversación abordó estas transformaciones:

### Columna SIZE (Solución #1)
```
Entrada: "19M", "103k", "", NULL
Transformación:
  - M → × 1,000,000
  - k → × 1,000
  - Vacío/NULL → MEDIA calculada
Salida: FLOAT (bytes)
Función: normalize_size(p_size TEXT) → FLOAT
```

### Columna CONTENT_RATING (Solución #2)
```
Entrada: "Everyone", "Teen", "Mature 17+", "Unrated", NULL
Transformación:
  - Everyone → 1
  - Everyone 10+ → 2
  - Teen → 3
  - Mature 17+ → 4
  - Adults only 18+ → 5
  - Unrated/NULL → 0
Salida: INT (0-5)
Función: normalize_content_rating(p_content_rating TEXT) → INT
Tabla ref: mapping_content_rating
```

### Columna TYPE (Solución Bonus)
```
Entrada: "Free", "Paid", NULL
Transformación:
  - Free → 0
  - Paid → 1
  - NULL → 0
Salida: INT (0-1)
Función: normalize_app_type(p_type TEXT) → INT
Tabla ref: mapping_app_type
```
